# M-Tap SVG illustration pack

Eight standalone editable SVGs:
- 01 Tap to pay — hero visual and payment explanation
- 02 Instant settlement — merchant payout benefit
- 03 Secure transactions — security / PIN authorization
- 04 Easy activation — tag setup and onboarding
- 05 Financial overview — settlement and transaction dashboard
- 06 Merchant empowerment — merchant benefits section
- 07 Seamless connectivity — technology / integration section
- 08 Payment success — confirmation and success states

`mtap-website-placement.svg` is an editable page-placement concept showing the recommended locations.

Palette: `#FFCC00` yellow, `#000000` black, `#FFFFFF` white, with restrained charcoal/slate supporting tones.

Next.js: put the files in `public/illustrations/` and use `<Image src="/illustrations/01-tap-to-pay.svg" alt="Tap to pay" width={800} height={600} />`.
